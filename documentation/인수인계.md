# 시선교회 웹사이트 인수인계

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 교회명 | 시선교회 |
| 목적 | 시광교회(seetheglory.or.kr)와 유사한 형태의 교회 소개 사이트 |
| 저장소 | https://github.com/considerlabs/seesun |
| 프로덕션 URL | https://seesun-church.vercel.app |
| Vercel 프로젝트 | `briank-projects/seesun-church` |
| 기본 브랜치 | `main` (푸시 시 자동 배포) |

콘텐츠 원본은 `docs/`(기획 PPT/TXT)와 `src/lib/content.ts`(사이트에 반영된 문구)입니다.

## 2. 기술 스택

- **Framework**: Next.js 16 (App Router)
- **UI**: React 19, Tailwind CSS v4, Pretendard
- **아이콘**: `@phosphor-icons/react`
- **모션**: `motion`
- **호스팅**: Vercel (Node.js 24.x)
- **인증/DB/결제**: 없음 (정적 공개 사이트)

## 3. 로컬 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드 검증
npm run start    # 빌드 결과 로컬 실행
```

Vercel CLI (배포·프로젝트 연결):

```bash
vercel whoami
vercel link          # 이미 .vercel/ 에 연결됨
vercel --prod        # 프로덕션 배포
```

## 4. 디렉터리 구조

```
src/
  app/                 # 라우트 (페이지)
  components/          # Header, Footer, PageHero, Reveal 등
  lib/content.ts       # 교회 정보·메뉴·교역자·공지·설교 등 콘텐츠
public/img/            # 웹에서 서빙되는 이미지 (교역자 사진 등)
img/                   # 원본 이미지 보관용 (동일 파일)
docs/                  # 기획 자료 (로컬에만 있을 수 있음)
documentation/         # 인수인계·문서
```

## 5. 페이지 맵

| 경로 | 설명 |
|------|------|
| `/` | 홈 (히어로, 소개, 예배, 공지·설교 요약) |
| `/about` | 교회 소개 |
| `/creed` | 신앙고백 |
| `/gospel` | 복음의 내용 |
| `/staff` | 섬기는 사람들 (사진 포함) |
| `/planting` | 개척이야기 |
| `/city` | 도시사역 (Come and see) |
| `/visit` | 처음 방문 가이드 (시광교회 firstguide와 동일 STEP 구조) |
| `/sermons` | 설교 (업로드 예정) |
| `/notices` | 공지사항 |
| `/magazine` | 월간지 (준비 중) |
| `/sunday-school` | 주일학교 |

공통 레이아웃: `src/components/Header.tsx`, `Footer.tsx`

## 6. 콘텐츠 수정 방법

대부분 **`src/lib/content.ts`** 를 수정하면 됩니다.

| 데이터 | 용도 |
|--------|------|
| `church` | 교회명, 위치, 연락처, 표어 |
| `navigation` | GNB 메뉴 |
| `staff` | 교역자 이름·역할·소개·사진 경로 |
| `notices` | 공지 목록 |
| `sermons` | 설교 목록 |
| `sundaySchool` | 주일학교 시간표 |
| `plantingVideos` | 개척이야기 영상 슬롯 |

긴 본문(교회소개, 신앙고백 등)은 각 `src/app/*/page.tsx` 안에 있습니다.

### 교역자 사진

| 파일 | 인물 |
|------|------|
| `public/img/park.png` | 박현진 목사 |
| `public/img/oh.png` | 오로라 전도사 |

교체 시 `public/img/` 에 같은 파일명으로 덮어쓰거나, `content.ts`의 `staff[].image` 경로를 바꾸면 됩니다.

## 8. 배포·운영 메모

1. `main` 푸시 → GitHub 연동으로 Vercel 프로덕션 배포
2. 수동 배포: `vercel --prod`
3. **SSO 배포 보호는 꺼 둔 상태**입니다. 다시 켜면 비로그인 사용자에게 404/SSO 리다이렉트가 납니다.
   - 확인: `vercel project protection seesun-church`
   - 끄기: `vercel project protection disable seesun-church --sso`
4. 프로덕션 도메인: `seesun-church.vercel.app`
5. `.env.local`, `.vercel/` 은 gitignore 대상입니다. 시크릿 환경변수는 현재 사용하지 않습니다.
