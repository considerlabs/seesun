## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 교회명 | 시선교회 (대한예수교 장로회) |
| 영문명 | SEE SUN CHURCH |
| 목적 | 시광교회(seetheglory.or.kr)와 유사한 형태의 교회 소개 사이트 |

| Vercel 팀/프로젝트 | `briank-projects` / `seesun-church` |
| 기본 브랜치 | `main` |

콘텐츠 원본은 `docs/`(기획 PPT/TXT)와 `src/lib/content.ts`(사이트에 반영된 공통 데이터)입니다. 페이지별 긴 본문은 각 `src/app/*/page.tsx`에 있습니다.

## 2. 기술 스택

- **Framework**: Next.js 16 (App Router)
- **UI**: React 19, Tailwind CSS v4, Pretendard
- **아이콘**: `@phosphor-icons/react`
- **모션**: `motion`
- **호스팅**: Vercel (Node.js 24.x, Fluid Compute)
- **인증/DB/결제**: 없음 (정적 공개 사이트)

## 3. 로컬 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드 검증
npm run start    # 빌드 결과 로컬 실행
```

Vercel CLI:

```bash
vercel whoami
vercel link          # .vercel/ 에 연결됨
vercel --prod --yes  # 프로덕션 배포
```

## 10. 배포·운영 메모

1. `main` 푸시 후 Vercel 연동 배포가 동작할 수 있으나, CLI로 `vercel --prod` 하는 경우가 많습니다.
2. **중요**: `vercel --prod` 후 `seesun-church.vercel.app` 가 자동으로 안 바뀌는 경우가 있습니다. 배포 URL을 확인한 뒤 별칭을 다시 걸어야 합니다.

```bash
vercel --prod --yes
# 출력의 Production URL 예: https://seesun-church-xxxxx-briank-projects.vercel.app
vercel alias set <deployment-url> seesun-church.vercel.app --scope briank-projects
```

3. **SSO 배포 보호는 꺼 둔 상태**입니다. 다시 켜면 비로그인 사용자 접근이 막힙니다.
   - 확인: `vercel project protection seesun-church`
   - 끄기: `vercel project protection disable seesun-church --sso`
4. `.env.local`, `.vercel/` 은 gitignore. 시크릿 환경변수 미사용.
5. Vercel CLI가 오래됐다면: `npm i -g vercel@latest` 권장.
